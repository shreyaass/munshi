1. Web App URL Must end in /exec
Why is this blank? Google Sheets dialogs cannot read your /exec URL automatically (they only see a broken /dev test URL).

Open Extensions → Apps Script → Deploy → Manage deployments (or New deployment → Web app), copy the Web app URL ending in /exec, and paste + Save it above.
