# Test the sheet end to end

You need three things in this folder:

| File | What it is |
|---|---|
| `ExpenseManager-template.xlsx` | The database. Upload this to Drive. |
| `AppsScript.gs` | The whole backend as one paste-ready file. |
| `SETUP.md` | This guide. |

`AppsScript.gs` is generated from `apps/script/*.gs` by `node sheet/bundle.mjs`.
Edit the sources, not the generated copy.

## 1. Upload the sheet

1. Go to [drive.google.com](https://drive.google.com) → **New → File upload** →
   choose `sheet/ExpenseManager-template.xlsx`.
2. Double-click it, then **File → Save as Google Sheets**.
   You now have a real Google Sheet with all tabs, headers, seeds and formatting.
   The original `.xlsx` can be deleted.

## 2. Install the backend

1. In the sheet: **Extensions → Apps Script**.
2. In the editor, click `Code.gs`, select all of its content, delete it, and
   paste the entire contents of `sheet/AppsScript.gs`.
3. **File → New → HTML file**, name it `ConnectionInfo`, and paste
   `apps/script/ConnectionInfo.html`.
4. Open **Project Settings** (gear icon) and tick
   **Show "appsscript.json" manifest file in editor**.
   Open `appsscript.json` and replace its contents with
   `apps/script/appsscript.json`.
5. **Save** (Ctrl+S).

## 3. Set up the sheet

1. Reload the Google Sheet tab.
2. **Expense Tracker → 1. Setup / repair sheet**.
3. Approve the Google permission prompt (the script runs as you, on this sheet).
4. Accept the dialog. Setup will:
   - append any missing columns (it never moves your data),
   - seed categories and budgets if those tabs are empty,
   - generate the **View** and **Read me** tabs,
   - create the access token.

   `Accounts` is intentionally left empty — the app asks for your first account
   (and its real current balance) the first time you connect.

## 4. Deploy the Web App

1. Back in Apps Script: **Deploy → New deployment**.
2. Gear → **Web app**.
3. **Execute as: Me** · **Who has access: Anyone**.
   "Anyone" means anyone *with the URL + token*; the sheet stays private.
4. **Deploy**, then authorize again if asked.
5. Copy the **Web app URL** (ends in `/exec`).

## 5. Connect the app

1. In the sheet: **Expense Tracker → 2. Show connection info**.
2. Copy the URL and the token.
3. Run the app (`npm run dev`), open it, paste both on the Connect screen.
4. Add a test expense of ₹1. Confirm:
   - the app says **Synced**,
   - a row appears in the `Expenses` tab with `amount_paise = 100`,
   - the `View` tab shows it as ₹1.00 with the category and account names.

## If something fails

| Symptom | Fix |
|---|---|
| Connect says "That is not a Web App URL" | The URL must be `https://script.google.com/macros/s/XXXX/exec`. |
| "unauthorized: bad token" | Re-run **Show connection info**; if needed, **Rotate access token** and reconnect. |
| "Setup has not been run" | Run **Expense Tracker → 1. Setup / repair sheet**. |
| Browser blocks the request (CORS) | Tell me the exact console error. Fallback is a ~30-line Cloudflare Worker proxy; the APK will not need it. |
| `View` formulas look empty | Check the `Expenses` tab has rows, then run Setup again. |
| You changed the script later | Deploy → **Manage deployments** → edit → **New version**, else the URL keeps serving old code. |

## Rules for the sheet

- Amounts are **integer paise**: `12500` = ₹125.00.
- Dates are `YYYY-MM-DD` text.
- Never delete rows and never edit `id`, `created_at`, `updated_at`, `device_id`
  or `deleted`. Deletes from the app are tombstones.
- Extra columns are preserved; required columns must keep their names.
- Budgets: `month = *` (every month) or `YYYY-MM`; `kind = total | daily | category`.
- `View` and `Read me` are generated by Setup and are not synced.
